# 💖 ShopAssist AI 2.0 — Pink Edition (React & Streamlit)

> **Developed by**: [Divya Paradkar](https://github.com/divyaparadkar)

An intelligent, interactive **Natural Language Processing (NLP) Customer Support Assistant & Intent Management Workbench** built with React + Vite and Streamlit.

---

## ✨ Key Features

- **🌸 Pink & Amethyst Purple Aesthetic**: Radiant neon glassmorphism UI with custom themes in both React & Streamlit.
- **💬 ShopBot Chat**: Intelligent NLP classification, 1-click Quick Action Assistant, instant order lookup, carrier tracking timeline, instant order cancellation, and interactive policy widgets.
- **⚙️ Intent Studio**: Live intent training workbench allowing users to create, edit, or delete intent tags, modify training patterns and responses, run live classifier tests with score rankings, and export `intents.json`.
- **📦 Orders Sandbox**: Real-time order status simulator (Processing, In Transit, Delivered, Canceled) with dynamic bot tracking updates.
- **📊 NLP Metrics & Performance**: Metrics cards, pattern distribution charts, and model architecture documentation.

---

## 🚀 Running the Applications

### 1. Run the Streamlit Application (Python)
```bash
# Run Streamlit on port 8501
streamlit run app.py --server.port 8501
```
Access at: `http://localhost:8501`

### 2. Run the React + Vite Application
```bash
# Install dependencies (if needed)
npm install

# Start Vite Development Server
npm run dev
```
Access at: `http://localhost:5173`
